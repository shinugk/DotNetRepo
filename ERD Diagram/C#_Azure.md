
Skills to Include in Your Resume
--------------------------------
In the skills section and work experience descriptions, use specific action verbs and quantify your achievements where possible. 
- Azure Services: Azure App Service (for hosting APIs), Azure Functions (for serverless computing), Azure SQL Database and Azure Cosmos DB (for data storage).
- DevOps & Tools: Azure DevOps (Pipelines for CI/CD, Azure Repos for source control), Git, and possibly Infrastructure as Code tools like ARM templates or Bicep.
- Security & Identity: Azure Key Vault (for managing secrets, keys, and certificates), and understanding Microsoft Entra ID (formerly Azure AD) for authentication/authorization (e.g., OAuth 2.0, JWT).
- Monitoring & Optimization: Experience with Azure Monitor and Application Insights for monitoring performance and diagnosing issues. 


Common Azure Interview Questions
----------------------------------------------
- Interview questions for a developer role will focus on practical application and best practices within the Azure ecosystem. 
- PaaS vs. IaaS: What is the difference between PaaS (Platform as a Service) and IaaS (Infrastructure as a Service), and when would you choose one over the other for a Web API project?
- Hosting and Deployment: How have you deployed a .NET Web API to Azure App Service?
- CI/CD: Can you explain how you would set up a CI/CD pipeline in Azure DevOps to build and deploy a .NET application?
- Security: How do you manage connection strings and other secrets securely in an Azure application? (The expected answer is often using Azure Key Vault with Managed Identities).
- Data Storage: When would you use Azure SQL Database versus Azure Cosmos DB for a Web API's data storage?
- Serverless: Have you used Azure Functions? Describe a use case in a Web API context (e.g., background tasks, event-driven processing).
- Monitoring: How do you monitor the health and performance of your application in Azure? (Mention Application Insights and Azure Monitor).
- Networking Basics: Can you explain the purpose of a Network Security Group (NSG) in Azure?
- Architecture: Have you worked with microservices or containerization (Docker, Azure Kubernetes Service or AKS)?
